## MCP recommandés (gratuits / self-host)

- Ce repo : `apps/mcp-server`
- Playwright MCP (Microsoft) — QA des sites générés
- GitHub MCP — déjà connecté sur ce compte
- Filesystem MCP — édition locale
- Brave Search MCP — recherche web sans clé payante si self-host

## Ce qu’il ne faut pas faire au départ

- Payer un BaaS (Supabase Pro, Firebase Blaze) avant d’avoir 1 salon réel
- Brancher une caisse NF525 avant le product-market fit
- Multiplier les LLM cloud : un seul + MCP suffit
